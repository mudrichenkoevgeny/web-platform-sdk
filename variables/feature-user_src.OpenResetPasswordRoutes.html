  • ReadonlyRESET_EMAIL_PASSWORD: "/auth/reset-password"
    • HTTP method: POST

    Resets a forgotten password or sets up an initial password using a previously sent confirmation code or invitation token.

    Request body: ResetPasswordRequest. Response body: None (204 No Content).

    Authorization:

    • Public Access: Allowed.
    • Allowed Roles: USER (OR semantics).
    • Allowed Account Statuses: ACTIVE, READ_ONLY, PENDING_DELETION (OR semantics).
    • Required Permissions: None.

    Audit logging: Persist an AuditEventPrivate for successful execution and all failed attempts.

    • Action: RESET_PASSWORD.
    • Actor: USER. Set actorId to the UserId only upon successful reset.
    • Resource: USER. Set resourceId to the UserId upon success; leave unset for failed attempts.
    • Metadata: Include:
    1. ClientInfo (see CommonAuditMetadataKey).
    2. EMAIL_ADDRESS — email address from the request.
