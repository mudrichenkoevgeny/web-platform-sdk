  • Route paths for authentication settings in the management API.

GET and PUT share the same path; the management prefix distinguishes them from the open read-only auth-settings route (no management prefix, open slice).

  • ReadonlyRESET_MANAGEMENT_AUTH_SETTINGS: "/management/settings/auth/reset"
    • HTTP method: POST

    Resets global authentication settings to default values.

    Request body: None. Response body: ManagementAuthSettingsPayload.

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: STAFF, ADMIN (OR semantics).
    • Allowed Account Statuses: ACTIVE (OR semantics).
    • Required Permissions: AUTH_SETTINGS_UPDATE (AND semantics).

    Security: Sensitive administrative operation. Requires mandatory MFA setup on the manager's account; returns TOTP_NOT_ENABLED if TOTP is not configured. When enabled, MFA Step-up is required via MFA_CONFIRMATION_REQUIRED. Session must be verified via REAUTHENTICATE_SESSION if stale.

    Audit logging: Persist an AuditEventPrivate for successful resets and all failed attempts.

    • Action: MANAGEMENT_RESET_AUTH_SETTINGS.
    • Actor: USER. Set actorId to the UserId of the administrator performing the reset.
    • Resource: AUTH_SETTINGS. Leave resourceId unset (singleton resource).
    • Metadata: Include:
    1. ClientInfo (see CommonAuditMetadataKey).

    UI Presentation:
