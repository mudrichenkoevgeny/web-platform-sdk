  • User-specific keys for error arguments used in API responses and backend logging.

Type declaration

  • ReadonlyACCOUNT_LOCKOUT_TYPE: "accountLockoutType"
    • Key for the lockout category (AccountLockoutType: NONE, INDEFINITE, TEMPORARY). Used as a public argument for client-side localization and behavior handling.

    Associated with USER_LOCKED.

  • ReadonlyDISPLAY_NAME: "displayName"
    • Key for user display name string.
  • ReadonlyDISPLAY_NAME_MAX_LENGTH: "displayNameMaxLength"
    • Key for maximum allowed display name character length. Associated with DISPLAY_NAME_TOO_LONG.
  • ReadonlyDISPLAY_NAME_MIN_LENGTH: "displayNameMinLength"
    • Key for minimum allowed display name character length. Associated with DISPLAY_NAME_TOO_SHORT.
  • ReadonlyMAX_NUMBER_OF_IDENTIFIERS: "maxNumberOfIdentifiers"
    • Key for the maximum number of identifiers allowed for the specific request context. Used as a public argument for client-side localization.

    Associated with USER_IDENTIFIER_LIMIT_REACHED, TOTAL_USER_IDENTIFIERS_LIMIT_REACHED.

  • ReadonlyNICKNAME: "nickname"
    • Key for user nickname string. Associated with NICKNAME_ALREADY_TAKEN.
  • ReadonlyNICKNAME_MAX_LENGTH: "nicknameMaxLength"
    • Key for maximum allowed nickname character length. Associated with NICKNAME_TOO_LONG.
  • ReadonlyNICKNAME_MIN_LENGTH: "nicknameMinLength"
    • Key for minimum allowed nickname character length. Associated with NICKNAME_TOO_SHORT.
  • ReadonlyTEMPORARY_LOCKOUT_UNTIL: "temporaryLockoutUntil"
    • Key for the temporary account lockout expiration timestamp in epoch milliseconds. Used as a public argument for client-side localization and countdown timers.

    Associated with USER_LOCKED. Present only during temporary lockouts with the expiration timestamp; absent for indefinite lockouts.

  • ReadonlyUSER_AUTH_PROVIDER: "userAuthProvider"
    • Key for the specific UserAuthProvider (see UserAuthProvider). Used as a public argument for client-side localization.

    Associated with USER_IDENTIFIER_LIMIT_REACHED.

  • ReadonlyUSER_ID: "userId"
    • Key for the unique identifier of the user related to the error. Mostly used as a secret argument for internal logging.

    Associated with USER_ROLE_NOT_ALLOWED, USER_MISSING_PERMISSIONS, USER_ILLEGAL_ACCOUNT_STATUS, USER_BANNED, USER_LOCKED, USER_READ_ONLY, USER_SECURITY_HOLD, USER_PENDING_DELETION, USER_FORBIDDEN, USER_NOT_FOUND.
