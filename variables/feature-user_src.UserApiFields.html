  • User-feature naming conventions for JSON request bodies, response fields, and filter/sort query keys that belong to this module’s HTTP contracts (authentication, users, identifiers, sessions, and related configuration).

Values are stable wire strings shared by server and clients; use these constants with @SerialName on DTOs and when documenting endpoints.
