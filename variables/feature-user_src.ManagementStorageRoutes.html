  • ReadonlyDELETE_FILE: "/management/storage/files/{fileId}"
    • HTTP method: DELETE

    Deletes a specific file and removes its binary from S3, ignoring ownership.

    Path parameter: FILE_ID.

    Request body: None. Response body: None (204 No Content).

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: UserRole.STAFF, UserRole.ADMIN (OR semantics).
    • Allowed Account Statuses: UserAccountStatus.ACTIVE (OR semantics).
    • Required Permissions: STORAGE_DELETE_OTHER_USERS_FILES.
    • Authority Level: Actor's level must be strictly greater than the target file owner's authority level.

    Audit logging: Persist an AuditEventPrivate for successful execution and all failed attempts.

    • Action: MANAGEMENT_DELETE_FILE.
    • Actor: USER. Set actorId to the administrator performing the deletion.
    • Resource: STORAGE_FILE. Set resourceId to the FILE_ID.
    • Metadata: Include:
    1. ClientInfo (see CommonAuditMetadataKey).
    2. FILE_NAME — the original name of the deleted file.
    3. FILE_SIZE_BYTES — the binary size of the deleted file in bytes.
    4. CATEGORY — the storage classification category of the deleted file.
    5. S3_KEY — the internal S3 object key or storage path of the deleted file.

  • ReadonlyGET_FILES: "/management/storage/files"
    • HTTP method: GET

    Returns a paged list of all storage files across the platform for administrative inspection.

    Pagination & sort (names from ListingParamNames):

    • PAGE_NUMBER — one-based page index (1 is the first page).

    • PAGE_SIZE — page size.

    • SORT_BY — exactly one of:

    • CREATED_AT

    • UPDATED_AT

    • FILE_NAME

    • FILE_SIZE_BYTES

    • SORT_ORDER — exactly one of:

    • ASC

    • DESC

    • Filters (StorageFileFilterValues): all filters are optional. Multi-value filters use repeated query keys with OR semantics; different keys combine as AND.

    • Multi-value Include Filters (repeated query keys, OR semantics):

    • FILE_ID — filter by one or more specific file IDs.

    • OWNER_USER_ID — filter by one or more owner user IDs.

    • CATEGORY — filter by one or more StorageCategory serial names.

    • VISIBILITY — filter by one or more StorageFileVisibility serial names.

    • STATUS — filter by one or more StorageFileStatus serial names.

    • TARGET_SCOPE — filter by one or more target scope or feature context strings.

    • Multi-value Exclude Filters (repeated query keys, NOT IN semantics):

    • EXCLUDE_CATEGORY — exclude specific StorageCategory serial names.

    • EXCLUDE_VISIBILITY — exclude specific StorageFileVisibility serial names.

    • EXCLUDE_STATUS — exclude specific StorageFileStatus serial names.

    • Exact Filters:

    • FILE_NAME — filter by exact original file name.

    • MIME_TYPE — filter by exact MIME type.

    • Presence Filters:

    • IS_OWNER_USER_ID_SET — filter by whether file has an owner user ID.

    • IS_TARGET_SCOPE_SET — filter by whether target scope is assigned.

    • IS_UPDATED_AT_SET — filter by whether file record has been updated.

    • Range Bounds (inclusive bounds):

    • FILE_SIZE_BYTES_FROM — inclusive lower bound for file size in bytes.

    • FILE_SIZE_BYTES_TO — inclusive upper bound for file size in bytes.

    • CREATED_AT_FROM — inclusive lower bound creation timestamp.

    • CREATED_AT_TO — inclusive upper bound creation timestamp.

    • UPDATED_AT_FROM — inclusive lower bound update timestamp.

    • UPDATED_AT_TO — inclusive upper bound update timestamp.

    • Free-text Search:

    • SEARCH_QUERY — free-text search query string targeting:

    • Original file name (fileName).

    Request body: None. Response body: PagedResult of StorageFileSummaryPayload.

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: UserRole.STAFF, UserRole.ADMIN (OR semantics).
    • Allowed Account Statuses: UserAccountStatus.ACTIVE, UserAccountStatus.READ_ONLY (OR semantics).
    • Required Permissions: STORAGE_VIEW_OTHER_USERS_FILES.
    • Authority Level: Actor's level must be strictly greater than the target file owner's authority level.
