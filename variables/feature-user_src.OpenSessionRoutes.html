  • ReadonlyGET_SESSIONS: "/user/sessions"
    • HTTP method: GET

    Returns active summary sessions for the current authenticated user (self-service).

    Pagination & sort (names from ListingParamNames):

    • PAGE_NUMBER — one-based page index (1 is the first page).

    • PAGE_SIZE — page size.

    • SORT_BY — exactly one of:

    • EXPIRES_AT

    • LAST_ACCESSED_AT

    • LAST_REAUTHENTICATED_AT

    • CREATED_AT

    • UPDATED_AT

    • SORT_ORDER — exactly one of:

    • ASC

    • DESC

    • Filters (UserSessionFilterValues): all filters are optional. Multi-value filters use repeated query keys with OR semantics; different keys combine as AND.

    • Multi-value Include Filters (repeated query keys, OR semantics):

    • SESSION_ID — filter by one or more specific session IDs.

    • IDENTIFIER_ID — filter by one or more login identifier IDs.

    • IDENTIFIER_AUTH_PROVIDER — filter by one or more UserAuthProvider serial names.

    • CLIENT_TYPE — filter by one or more ClientType serial names.

    • Multi-value Exclude Filters (repeated query keys, NOT IN semantics):

    • EXCLUDE_IDENTIFIER_AUTH_PROVIDER — exclude UserAuthProvider serial names.

    • Exact Filters:

    • IDENTIFIER — filter by exact raw or masked login identifier string.

    • IDENTIFIER_DISPLAY_NAME — filter by exact identifier display name.

    • DEVICE_ID — filter by exact stable device ID.

    • DEVICE_NAME — filter by exact device name.

    • APP_VERSION — filter by exact application version.

    • OPERATION_SYSTEM_VERSION — filter by exact operating system version.

    • USER_AGENT — filter by exact HTTP User-Agent string.

    • IP_ADDRESS — filter by exact raw or masked IP address.

    • Presence Filters:

    • IS_USER_AGENT_SET — filter by whether User-Agent header is present.

    • IS_IP_ADDRESS_SET — filter by whether IP address is present.

    • IS_UPDATED_AT_SET — filter by whether record has been updated.

    • Range Bounds (inclusive bounds):

    • EXPIRES_AT_FROM — inclusive lower bound expiration timestamp.

    • EXPIRES_AT_TO — inclusive upper bound expiration timestamp.

    • LAST_ACCESSED_AT_FROM — inclusive lower bound last accessed timestamp.

    • LAST_ACCESSED_AT_TO — inclusive upper bound last accessed timestamp.

    • LAST_REAUTHENTICATED_AT_FROM — lower bound re-authentication timestamp.

    • LAST_REAUTHENTICATED_AT_TO — upper bound re-authentication timestamp.

    • CREATED_AT_FROM — inclusive lower bound creation timestamp.

    • CREATED_AT_TO — inclusive upper bound creation timestamp.

    • UPDATED_AT_FROM — inclusive lower bound update timestamp.

    • UPDATED_AT_TO — inclusive upper bound update timestamp.

    • Free-text Search:

    • SEARCH_QUERY — free-text search query string targeting:

    • Raw or masked login identifier (identifier).

    • Identifier display name (identifierDisplayName).

    • Device name (deviceName).

    Request body: None. Response body: PagedResult of UserSessionSummaryPayload.

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: USER (OR semantics).
    • Allowed Account Statuses: Any UserAccountStatus (OR semantics).
    • Required Permissions: None.

    UI Presentation:

    • Screens:
    • SessionList
