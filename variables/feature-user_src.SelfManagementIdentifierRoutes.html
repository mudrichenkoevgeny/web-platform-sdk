  • ReadonlyGET_IDENTIFIERS: "/management/self/user/identifiers"
    • HTTP method: GET

    Returns summary identifiers linked to the current authenticated management account.

    Pagination & sort (names from ListingParamNames):

    • PAGE_NUMBER — one-based page index (1 is the first page).

    • PAGE_SIZE — page size.

    • SORT_BY — exactly one of:

    • CREATED_AT

    • UPDATED_AT

    • IDENTIFIER

    • DISPLAY_NAME

    • SORT_ORDER — exactly one of:

    • ASC

    • DESC

    • Filters (UserIdentifierFilterValues): all filters are optional. Multi-value filters use repeated query keys with OR semantics; different keys combine as AND.

    • Multi-value Include Filters (repeated query keys, OR semantics):

    • IDENTIFIER_ID — filter by one or more specific identifier IDs.

    • USER_AUTH_PROVIDER — filter by one or more UserAuthProvider serial names.

    • Multi-value Exclude Filters (repeated query keys, NOT IN semantics):

    • EXCLUDE_USER_AUTH_PROVIDER — exclude specific UserAuthProvider serial names.

    • Exact Filters:

    • IDENTIFIER — filter by exact raw or masked login identifier string.

    • DISPLAY_NAME — filter by exact display name.

    • EXTERNAL_PROVIDER_EMAIL — filter by exact external provider email.

    • Presence Filters:

    • IS_EXTERNAL_PROVIDER_EMAIL_SET — filter by external provider email presence.

    • IS_UPDATED_AT_SET — filter by whether record has been updated.

    • Range Bounds (inclusive bounds):

    • CREATED_AT_FROM — inclusive lower bound creation timestamp.

    • CREATED_AT_TO — inclusive upper bound creation timestamp.

    • UPDATED_AT_FROM — inclusive lower bound update timestamp.

    • UPDATED_AT_TO — inclusive upper bound update timestamp.

    • Free-text Search:

    • SEARCH_QUERY — free-text search query string targeting:

    • Raw or masked login identifier (identifier).

    • Display name (displayName).

    • External provider email (externalProviderEmail).

    Request body: None. Response body: PagedResult of UserIdentifierSummaryPayload.

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: STAFF, ADMIN (OR semantics).
    • Allowed Account Statuses: ACTIVE, READ_ONLY (OR semantics).
    • Required Permissions: None.

    UI Presentation:

    • Screens:
    • IdentifierList

  • ReadonlyIDENTIFIER_EMAIL_CHANGE_PASSWORD: "/management/self/user/identifiers/{user_identifier_id}/change-password"
    • HTTP method: POST

    Updates the management account password using current credentials.

    Path parameter: USER_IDENTIFIER_ID.

    Request body: EmailPasswordChangeRequest. Response body: None (204 No Content).

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: STAFF, ADMIN (OR semantics).
    • Allowed Account Statuses: ACTIVE, READ_ONLY (OR semantics).
    • Required Permissions: None.

    Security: Sensitive operation. MFA Step-up required (if enabled for the account). Returns MFA_CONFIRMATION_REQUIRED if additional verification is needed. Session must be verified via REAUTHENTICATE_SESSION if stale.

    Audit logging: Persist an AuditEventPrivate for successful execution and all failed attempts.

    • Action: CHANGE_PASSWORD.
    • Actor: USER. Set actorId to the current UserId.
    • Resource: IDENTIFIER. Set resourceId to the identifier record id associated with the password.
    • Metadata: Include:
    1. ClientInfo (see CommonAuditMetadataKey).
    2. SESSION_ID — the unique identifier of the authenticated session.
