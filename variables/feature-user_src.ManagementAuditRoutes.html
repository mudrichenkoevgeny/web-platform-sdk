  • ReadonlyGET_AUDIT_EVENT: "/management/audit/events/{event_id}"
    • HTTP method: GET

    Retrieves specific audit event details.

    Path parameter: EVENT_ID.

    Request body: None. Response body: AuditEventPrivatePayload.

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: UserRole.STAFF, UserRole.ADMIN (OR semantics).
    • Allowed Account Statuses: UserAccountStatus.ACTIVE, UserAccountStatus.READ_ONLY (OR semantics).
    • Required Permissions: Based on the event's actor type:
    • For USER: AUDIT_GET_FOR_USER_ACTOR_MASKED or AUDIT_GET_FOR_USER_ACTOR_UNMASKED.
    • For SYSTEM: AUDIT_GET_FOR_SYSTEM_ACTOR_MASKED or AUDIT_GET_FOR_SYSTEM_ACTOR_UNMASKED.
    • For SERVICE: AUDIT_GET_FOR_SERVICE_ACTOR_MASKED or AUDIT_GET_FOR_SERVICE_ACTOR_UNMASKED.
    • For Staff actors: AUDIT_GET_FOR_STAFF_ACTOR_MASKED or AUDIT_GET_FOR_STAFF_ACTOR_UNMASKED.
    • For Admin actors: AUDIT_GET_FOR_ADMIN_ACTOR_MASKED or AUDIT_GET_FOR_ADMIN_ACTOR_UNMASKED.

  • ReadonlyGET_AUDIT_EVENTS: "/management/audit/events"
    • HTTP method: GET

    Returns a paged list of condensed audit events.

    Pagination & sort (names from ListingParamNames):

    • PAGE_NUMBER — one-based page index (1 is the first page).

    • PAGE_SIZE — page size.

    • SORT_BY — exactly one of:

    • CREATED_AT

    • SORT_ORDER — exactly one of:

    • ASC

    • DESC

    • Filters (AuditEventFilterValues): all filters are optional. Multi-value filters use repeated query keys with OR semantics; different keys combine as AND.

    • Multi-value Include Filters (repeated query keys, OR semantics):

    • EVENT_ID — filter by one or more specific audit event record IDs.

    • ACTOR_ID — filter by one or more actor IDs.

    • ACTOR_TYPE — filter by one or more AuditActorType serial names.

    • ACTOR_USER_ROLE — filter by one or more user actor role snapshots.

    • ACTION — filter by one or more audit action names.

    • RESOURCE — filter by one or more audit resource names.

    • RESOURCE_ID — filter by one or more resource instance IDs.

    • STATUS — filter by one or more AuditStatus serial names.

    • Multi-value Exclude Filters (repeated query keys, NOT IN semantics):

    • EXCLUDE_ACTOR_TYPE — exclude specific AuditActorType serial names.

    • EXCLUDE_ACTION — exclude specific audit action names.

    • EXCLUDE_STATUS — exclude specific AuditStatus serial names.

    • Range Bounds (inclusive bounds):

    • CREATED_AT_FROM — inclusive lower bound creation timestamp.

    • CREATED_AT_TO — inclusive upper bound creation timestamp.

    • Free-text Search:

    • SEARCH_QUERY — free-text search query string targeting:

    • Event human-readable message (message).

    Request body: None. Response body: PagedResult of AuditEventSummaryPayload.

    Authorization:

    • Public Access: Denied.
    • Allowed Roles: UserRole.STAFF, UserRole.ADMIN (OR semantics).
    • Allowed Account Statuses: UserAccountStatus.ACTIVE, UserAccountStatus.READ_ONLY (OR semantics).
    • Required Permissions: Based on the event's actor type:
    • For USER: AUDIT_GET_FOR_USER_ACTOR_MASKED or AUDIT_GET_FOR_USER_ACTOR_UNMASKED.
    • For SYSTEM: AUDIT_GET_FOR_SYSTEM_ACTOR_MASKED or AUDIT_GET_FOR_SYSTEM_ACTOR_UNMASKED.
    • For SERVICE: AUDIT_GET_FOR_SERVICE_ACTOR_MASKED or AUDIT_GET_FOR_SERVICE_ACTOR_UNMASKED.
    • For Staff actors: AUDIT_GET_FOR_STAFF_ACTOR_MASKED or AUDIT_GET_FOR_STAFF_ACTOR_UNMASKED.
    • For Admin actors: AUDIT_GET_FOR_ADMIN_ACTOR_MASKED or AUDIT_GET_FOR_ADMIN_ACTOR_UNMASKED.
