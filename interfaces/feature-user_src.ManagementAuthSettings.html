Interface ManagementAuthSettings

Full authentication configuration edited through the management API. Superset of OpenAuthSettings: includes the same provider lists plus token lifetime policy for issued credentials. Server implementations apply updates without restart; already issued tokens may retain semantics from the previous policy until they expire or are deleted, unless the server documents otherwise.
