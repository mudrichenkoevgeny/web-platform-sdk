# Getting Started with Web Platform SDK

The Web Platform SDK provides modular Clean Architecture primitives for standard and administrative identity, storage management, security policies, and application settings.

## Installation

Add the core and feature packages to your application using pnpm, npm, or yarn:

```bash
pnpm add @mudrichenkoevgeny/web-platform-sdk-core-common \
  @mudrichenkoevgeny/web-platform-sdk-core-security \
  @mudrichenkoevgeny/web-platform-sdk-core-settings \
  @mudrichenkoevgeny/web-platform-sdk-core-storage \
  @mudrichenkoevgeny/web-platform-sdk-feature-user \
  @mudrichenkoevgeny/web-platform-sdk-feature-clientuser
```

Add the development tooling package for automatic agent rules synchronization, ESLint presets, and code generators:

```bash
pnpm add -D @mudrichenkoevgeny/web-platform-sdk-tools
```

## Initializing the SDK Provider

Initialize `CommonComponent` in your application composition root and wrap your React component tree with `SdkProvider`:

```tsx
import React from 'react'
import { CommonComponent, SdkProvider } from '@mudrichenkoevgeny/web-platform-sdk-core-common'
import { LoginByEmailScreen } from '@mudrichenkoevgeny/web-platform-sdk-feature-clientuser'

export const App: React.FC<{ commonComponent: CommonComponent }> = ({ commonComponent }) => {
  return (
    <SdkProvider component={commonComponent}>
      <LoginByEmailScreen dependencies={dependencies} />
    </SdkProvider>
  )
}
```

## Error Handling Paradigm

All SDK use cases return discriminated unions (`AppResult<T, AppError>`) rather than throwing errors:

```ts
const result = await loginUseCase.execute({ email, password })

if (result.type === 'success') {
  console.log('Authenticated session:', result.data.session)
} else {
  console.error('Authentication error:', result.error.message)
}
```
